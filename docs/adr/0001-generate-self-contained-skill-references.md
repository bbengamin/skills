# Generate self-contained skill references from canonical docs

Skill installers and Claude/Cowork uploads consume one skill directory at a time, so every shipped skill must retain local `references/` files. We author shared material only in root `AGENTS.md`, `CONTEXT.md`, and `docs/**`, declare each bundle in `skill-references.json`, record generated ownership and content digests in `skill-references.lock.json`, and generate checked-in skill-local copies through one materializer. Cleanup removes only formerly generated content whose digest still matches; a modified path must be preserved and reported for an explicit ownership transfer. Packaging rejects every symlink in a skill tree so archives cannot dereference machine-local files. This preserves consumer locality while avoiding manual duplication; source symlinks and cross-skill dependencies were rejected because their behavior is not portable across hosted downloads, Windows checkouts, scanners, and selective installs.
